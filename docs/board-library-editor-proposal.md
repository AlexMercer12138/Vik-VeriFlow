# 图形化板卡编辑器方案

本次仅确定方案，不实现新增窗口。建议在约束面板的板卡下拉框旁增加“管理板卡”，打开独立的 VS Code Webview。新建、复制、编辑、导入和导出共用这个编辑器，保存到用户板卡库，所有工程可见。

板卡有数百引脚，首版采用可粘贴的表格录入，不制作封装引脚拖线图。

## 1. 基本信息和 Bank

填写板卡名称、厂商、完整 FPGA 器件型号。Bank 表记录 Bank ID、硬件类型和供电轨；供电轨填固定电压或允许电压列表，支持复制行、粘贴多行。

支持从厂商封装表或 CSV/TSV 导入引脚、Bank 和 P/N 配对，先预览列映射。没有文件时也能手工增行。器件库识别成功时预填 Bank 类型，未知器件保留手工录入并显示尚无生成规则。

## 2. 添加接口实例

搜索通用接口，选择后填写实例名和角色。位宽变体明确显示规格，不默认使用最大位宽。

从模板复制可制作自己的可复用接口，单独保存到用户接口库；只定义信号、方向、位宽、差分配对和分组，不含 FPGA 引脚或 Bank。板卡专用 CLK、LED、KEY 支持直接创建简短信号列表。

预览信号和分组，勾选实际接通的信号写入接口实例 `signals`，不为 HDMI 等可选边带另建定义。总线在定义里只有一个信号和数字位宽；实际位宽不同使用明确变体，接线表按位展开。

## 3. 接线表

按接口列出信号行，填写 FPGA 封装脚后自动显示 Bank。填写差分正脚后可根据封装表补齐负脚。支持从 Excel 复制“信号名 / 封装脚”两列直接粘贴。

在对应信号行填写板载时钟频率；预留引脚可选提示或禁用。多个接口引用同一封装脚时显示复用标记及所有引用，这是允许的硬件事实。重复信号映射、未知脚、差分错配和同一接口内部重复占脚作为错误阻止保存。不添加跳线字段。

## 4. 检查并保存

右侧始终显示问题列表，点击问题跳到对应单元格。底部预览接口数、已映射信号、复用脚和 Bank 供电。

保存前检查角色、信号覆盖、Bank 引用和差分极性，成功后板卡下拉框立即更新。提供“另存为新板卡”维护硬件版本、“导出 JSON”分享和版本管理。未保存修改关闭时使用 VS Code 现有确认方式。

编辑已有板卡前保留上一份配置，失败时恢复；删除前列出当前已打开 AD 的引用。此编辑器不填写 IO 标准，工程约束面板继续负责 Bank 电压和逐信号标准选择。

## 实施顺序

先做基本表单、接口选择和可粘贴接线表，覆盖从零录入和编辑 AU15P 的完整流程。随后加入引脚表导入、列映射和用户接口模板编辑。首版无需原理图解析、封装图或在线板卡商城。
