# 图形化板卡编辑器方案

已实施：约束面板的板卡下拉框旁增加“Manage Boards…”，打开独立的 VS Code 编辑器。命令面板也可执行 **VeriFlow: Manage Boards**。新建、复制、编辑、JSON 导入和导出共用这个编辑器，保存到用户板卡库，所有工程可见。

板卡有数百引脚，首版采用手动编辑的表格录入，不制作封装引脚拖线图。按 2026-10-15 的实施调整，首版不支持 CSV/TSV、厂商封装表导入、列映射或多行粘贴；仅保留板卡 JSON 导入/导出。

## 1. 基本信息和 Bank

填写板卡 ID、名称、厂商、完整 FPGA 器件型号。Bank 表记录 Bank ID、硬件类型和供电轨；供电轨填固定电压或允许电压列表，单位为毫伏，支持手动增行、复制行和移除行。

封装脚、Bank 和 P/N 配对均手工录入。AU15P 器件识别成功时预填已知 Bank 类型，未知器件保留手工录入并显示尚无生成规则。

## 2. 添加接口实例

搜索通用接口，选择后填写实例名和角色。位宽变体明确显示规格，不默认使用最大位宽。

从模板复制可制作自己的可复用接口，单独保存到用户接口库；只定义信号、方向、位宽、差分配对和分组，不含 FPGA 引脚或 Bank。板卡专用 CLK、LED、KEY 支持直接创建简短信号列表。

预览信号和分组，勾选实际接通的信号写入接口实例 `signals`，不为 HDMI 等可选边带另建定义。总线在定义里只有一个信号和数字位宽；实际位宽不同使用明确变体，接线表按位展开。

## 3. 接线表

按接口列出信号行，填写 FPGA 封装脚后自动显示 Bank。填写差分正脚后可根据手工录入的封装配对补齐空白负脚。

在对应信号行填写板载时钟频率；预留引脚可选提示或禁用。多个接口引用同一封装脚时显示复用标记及所有引用，这是允许的硬件事实。重复信号映射、未知脚、差分错配和同一接口内部重复占脚作为错误阻止保存。不添加跳线字段。

## 4. 检查并保存

右侧始终显示问题列表，点击问题跳到对应单元格。底部预览接口数、已映射信号、复用脚和 Bank 供电。

保存前检查角色、信号覆盖、Bank 引用和差分极性，成功后板卡下拉框立即更新。提供“另存为新板卡”维护硬件版本、“导出 JSON”分享和版本管理。未保存修改关闭时使用 VS Code 现有确认方式。

写入前保留用户配置的 `.bak`，通过临时文件原子替换，写入失败不改动原配置；外部编辑冲突会拒绝覆盖。删除前列出当前已打开 AD 的引用。此编辑器不填写 IO 标准，工程约束面板继续负责 Bank 电压和逐信号标准选择。

## 实施顺序

首版覆盖基本表单、接口选择、手动接线表和用户接口模板编辑，可从零录入或导入并编辑 AU15P。原理图解析、封装图、表格导入和在线板卡商城不在首版范围。

板卡 JSON 导出包含 `id`、`name`、`model`、`definitions`，携带接口快照。导入也兼容原有 `board.json` 加相对接口文件。保存时通用接口仍按内置库引用，用户模板与板卡专用接口保存快照。用户接口库保存在用户配置的 `boardInterfaces` 数组；更改模板不会自动重写已有板卡。
