# 开发计划

## 1.6.x 完整编程语言扩展计划

1. 支持 Verilog/SystemVerilog/XDC/SDC 等文件格式的语法高亮，快速模板等

2. 支持内置 Verilog/SystemVerilog Lint 功能，支持配置外部 Linter，选项依旧 builtin/custom

3. 支持在 AD 编辑器内编辑约束，并导出为各种格式

   - 物理模型仅保留约束生成、引脚/电平检查与模型映射所需字段。固定接口共用信号并按 function 选择角色；扩展接口差分脚可单端使用，子卡直接映射到扩展信号 ID。主板只记录厂商、器件、引脚、Bank、实际供电和接线，由生成器决定厂商约束。录入规范、JSON Schema 和示例见 [物理接口、板卡与子卡模型 V1](physical-interface-model.md)，真实板卡见 [ATK AU15P](boards/atk-au15p/README.md)（数据契约草案，尚未接入插件）。

## 1.7.x 波形查看器功能增强计划

1. 开发自定义波形格式，用二进制存储，优化性能

2. 扩展内置波形器的支持格式，支持常见格式以及自定义格式，支持列表参考 Surfur

3. 优化波形查看器界面，已发现问题有在高对比度主题下亮度过高，在信号列表拖动信号时总会插入偏下的位置
