# 开发计划

## 1.6.x 完整编程语言扩展计划

1. 已支持 Verilog/SystemVerilog/XDC/SDC 常用文件的语言识别、语法高亮、基础编辑配置，并接入上游 Verilog/SystemVerilog 代码片段；后续继续完善语言工具

2. 支持内置 Verilog/SystemVerilog Lint 功能，支持配置外部 Linter，选项依旧 builtin/custom

3. 支持在 AD 编辑器内编辑约束，并导出为各种格式

   - 单一约束工作台共用于 AD/RTL。板卡与子卡保存逐资源模板，Import board 只接受板卡 JSON；主板只替换信号名，子卡独立填写位置，无约束语法解析、主板映射或跨板占用检查。ID 自动生成，右侧端口拖入绑定。保持未发布模型 V1，见 [模型](physical-interface-model.md) 和 [使用说明](physical-pin-bindings.md)。

## 1.7.x 波形查看器功能增强计划

1. 开发自定义波形格式，用二进制存储，优化性能

2. 扩展内置波形器的支持格式，支持常见格式以及自定义格式，支持列表参考 Surfur

3. 优化波形查看器界面，已发现问题有在高对比度主题下亮度过高，在信号列表拖动信号时总会插入偏下的位置

## 1.8.x HDL 常用功能块模板计划

1. 在保留代码片段用于快速定位和补全的前提下，将 VeriFlow HDL 模板发展为可配置的常用功能块生成器。

2. 首批考虑计时器块、边沿捕获块、跨时钟域转换块等可直接复用的 RTL 功能块，支持参数配置、端口定义和实例化代码生成。

3. 功能块模板与语言片段分开维护：片段负责编辑器中的短语级插入，VeriFlow 模板负责生成完整、可配置的 RTL 结构。
