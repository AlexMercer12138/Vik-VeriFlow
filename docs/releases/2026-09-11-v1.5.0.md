# VeriFlow 1.5.0 发布交接

本次常规 minor 发布面向 `@veriflow/cli` 和 VS Code Marketplace 的
**Verilog Design Flow**（`Vikai-mercer.veriflow`）。实际发布由仓库所有者执行，
不创建 GitHub Release。

## 用户可见变化

- Verilog/SystemVerilog 文档格式化，格式化前后校验语法树。
- Design、Simulation、Results 三个工作流视图。
- 独立保存验证对象和 Testbench 入口的仿真任务，支持切换、重命名和配置。
- 主编辑区内的 Testbench 生成器，以及生成后立即运行。
- 图形设计仿真前校验和 RTL 导出、设计接口变化提示。
- 最近一次运行的日志、波形副本和结果过期提示。

完整变更见 [CHANGELOG](../../veriflow-vscode/CHANGELOG.md)。

## 所有者发布命令

在仓库根目录执行以下一条 Bash 命令，按依赖顺序发布全部 npm 包，CLI 最后发布。任一步失败都会立即停止并返回错误码，不会关闭当前终端：

```bash
(
  release_version='1.5.0'
  for release_package in flow-core hdl-core schematic-core hdl-runtime waveform-runtime simulator-iverilog-wasm waveform-desktop cli; do
    npm publish "dist/npm/veriflow-${release_package}-${release_version}.tgz" --access public || exit $?
  done
)
```

npm 包全部发布成功后，单独发布已构建的 VSIX：

```bash
npm exec -- vsce publish --packagePath veriflow-vscode/veriflow-1.5.0.vsix
```

发布后确认 npm 默认版本：

```bash
npm view @veriflow/cli version
```

并单独确认 [Marketplace 页面](https://marketplace.visualstudio.com/items?itemName=Vikai-mercer.veriflow)
的版本为 `1.5.0`。本地构建成功不表示远端已发布。
