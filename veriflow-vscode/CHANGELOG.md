# Change Log

## [1.5.1] - 2026-09-17

- 新增图形化 Testbench 生成界面 Simulation Task，可以导出为 TB 或直接运行仿真。
- 统一侧边栏风格，从上到下分别为模块浏览，架构设计，仿真任务。
- 过去的一键仿真功能转移至右键菜单。
- 修复大量已知问题。

## [1.5.0] - 2026-09-11

- 新增 Verilog/SystemVerilog 文档格式化，统一缩进与布局，并在格式化前后校验语法树以保护源代码。
- VS Code 侧栏重组为 Design、Simulation 和 Results，分别管理设计顶层、仿真任务及运行结果。
- 新增仿真任务创建、切换、重命名和配置，独立保存验证对象与 Testbench 仿真入口，并兼容已有仿真顶层设置。
- Testbench 生成器移至主编辑区，支持端口、参数、时钟、复位配置及生成后立即运行，保护已有 Testbench 文件不被覆盖。
- 图形设计创建和执行仿真任务前自动验证并导出 RTL，设计端口或参数变化时提示检查 Testbench。
- Results 展示最近一次运行的状态、波形副本和编译／运行日志，保留运行时的任务信息，并在源码变化后标记结果过期。

## [1.4.5] - 2026-09-03

- Arch Design 模块引用改用工作区相对标识，并可迁移旧版绝对路径和偏移标识，移动工程或修改源文件后仍能稳定解析。
- 修复带初始化值的 non-ANSI `output reg` 端口未被识别的问题。
- 改善 Arch Design 模块选择、定义跳转和复杂网络的原理图布线。

## [1.4.4] - 2026-09-03

- Arch Design 的悬空模块输入、Logic Utility 输入和 inout 控制默认值仅在属性栏、验证与 RTL 导出中生效，不再生成画布常量框或分支。
- 新增 Logic Utility（逻辑工具）入口，支持显式常量、非、与/或/异或及其反相形式、MUX、拼接、切片、复制、零/符号扩展和归约逻辑。
- Logic Utility 支持自动命名、连线、属性编辑、删除和快捷键，并以确定性的连续 `assign` 语句导出 RTL。
- Arch Design 升级到 schema v2；schema v1 文件仍可读取，并在编辑时迁移到新模型。

## [1.4.3] - 2026-09-02

- Arch Design 悬空模块输入默认连接常数 0，并支持在端口属性中修改默认值。
- 添加模块时支持按源文件区分同名定义，并按模块名自动生成独立递增的实例名。
- 为 Arch Design 常用编辑、布线、视图和导出操作补充快捷键。
- 参数化模块端口引出到顶层时会按实例参数计算数值位宽，生成可综合的 RTL。
- 模块定义刷新后自动移除已删除的参数覆盖，避免失效参数残留。
- 连接布线仅刷新路由并保持现有模块布局和视口，自动布局改由用户主动触发。
- 更新受影响的 npm 依赖，修复已知依赖漏洞。

## [1.4.2] - 2026-08-14

- 仿真默认使用内置 WASM 版 Icarus Verilog（Verilog-2005），无需安装本机仿真器。
- 波形默认使用内置 VCD 查看器；外部仿真器和波形工具统一通过 `custom` 命令模板配置。
- 新增 Arch Design 创建入口和 CLI 模板命令。
- 优化 AD 正交布线、顶层端口外观及端口提示。
- 修复画布操作误修改 AD 文件的问题，打开设计时自动居中。

## [1.4.1] - 2026-08-13

- 新增 `.ad` Arch Design 可视化编辑、接口聚合和 RTL 导出。
- 支持模块、顶层端口、参数、默认值及标量和总线连接编辑。
- 改善列布局、正交布线、端口选择和编辑交互。

## [1.4.0] - 2026-08-09

- 发布共享 TypeScript 核心、Node CLI 和 context-isolated Electron 波形窗口。
- Node CLI 与 VS Code 扩展共享 HDL、仿真和波形 runtime。
- Python GUI/CLI 进入弃用周期，在 retirement gate 完成前继续提供兼容制品。
- 扩展展示名由 Verilog Simulation Flow 更新为 Verilog Design Flow，扩展 ID 和配置键保持不变。
